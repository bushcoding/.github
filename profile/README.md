## Bush Coding

Software studio from Costa Rica. We build custom software for businesses and run our own products:

- **[Stash](https://stash.bushcoding.com)** — keep API keys and environment variables for every environment in one encrypted place and load them with one command.
- **[Aptly](https://aptly.bushcoding.com)** — appointment booking for businesses that work by appointment.
- **[Classify](https://classify.bushcoding.com)** — sorts the electronic invoices accountants in Costa Rica receive into sales and purchases by month, with an Excel summary.
